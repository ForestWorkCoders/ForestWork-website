# 林間小鎮 ForestWork — Brand Assets Guidelines

## 1. SVG Asset Summary (矢量資源清單)

Files are named by the colour of the artwork, not the background.

- **Emblem (圖案標)**: `logo-black.svg` (black artwork) / `logo-white.svg` (white artwork)
- **EN Logotype (英文字標)**: `text-en-black.svg` / `text-en-white.svg` (Tight ViewBox: `0 0 266 36`)
- **ZH Logotype (中文字標)**: `text-zh-black.svg` / `text-zh-white.svg` (Tight ViewBox: `0 0 400 90`)

## 2. Display Minimums (最小渲染高度)

- **Header Icon + Text**: `h-3.5` ~ `h-4` (Text) | `h-7` (Emblem)
- **Horizontal Lockup (橫向組合)**: Min height `45px`
- **Vertical Lockup (直向雙語組合)**: Min height `75px` (Emblem `h-14` > ZH `h-5` > EN `h-3.5`)

## 3. Usage Rules (使用鐵律)

- Do not stretch, distort, or modify SVG ViewBox aspect ratios.
- Always use `black` variants on white/light backgrounds (#FFFFFF / #F9FAFB).
- Always use `white` variants on dark/night backgrounds (#090A0F / #12141A).
