# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**. We'll reply there.

Useful details: what you found, the page or API route, and steps to reproduce.

## Scope

The site at forestwork.vercel.app, its API routes, and the Discord bot commands in this repository.
